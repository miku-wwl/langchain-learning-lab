# 06 — Multi-Agent Patterns

## Goal

Study how multiple agents or agent-like workers can coordinate through explicit roles and message or state handoffs.

## Learning Scope

- Define a small set of distinct worker responsibilities.
- Choose and explain a simple coordination pattern, such as a supervisor or routed handoff.
- Track shared state and the messages or results passed between workers.
- Verify routing, handoffs, and termination conditions deterministically where possible.

Build on the graph and tool concepts from earlier stages. Keep the number of workers and transitions small; avoid adding production orchestration.

## Suggested Learning Flow

Concept → architecture → code → run → result → why. Show each worker's input, output, and the coordinator's decision.
