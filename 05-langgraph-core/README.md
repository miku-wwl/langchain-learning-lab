# 05 — LangGraph Core

## Goal

Understand LangGraph's graph model by building a small stateful graph and tracing its execution.

## Learning Scope

- Define graph state and understand how updates are applied.
- Create nodes and connect them with edges.
- Add conditional routing and observe state transitions.
- Explore checkpointing or persistence only when it helps explain graph execution.

Keep the graph small enough to trace by hand. Focus on state, nodes, edges, and routing before introducing multi-agent patterns or larger workflows.

## Suggested Learning Flow

Concept → architecture → code → run → result → why. Record the initial state, node sequence, routing decision, and final state.
