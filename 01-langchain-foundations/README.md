# 01 — LangChain Foundations

## Goal

Learn the basic LangChain building blocks and how data moves through a simple application.

## Learning Scope

- Connect to an available local model/runtime.
- Build prompts and invoke a chat model.
- Compose a small chain and inspect its input and output.
- Parse or validate structured output where useful.

Keep this stage focused on core LangChain usage; agent loops, retrieval, and graph orchestration belong to later stages.

## Suggested Learning Flow

Concept → architecture → code → run → result → why. Keep the example minimal, then explain what each component contributes.
