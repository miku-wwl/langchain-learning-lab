# 07 — LangGraph Workflows

## Goal

Design and run a small workflow graph that makes routing, control flow, and state changes easy to inspect.

## Learning Scope

- Model a task as explicit graph state and focused nodes.
- Use sequential and conditional paths, with a bounded loop if the example needs one.
- Verify how the graph handles branches, retries, or human input when included.
- Explain how workflow control flow differs from an unconstrained agent loop.

Keep this stage focused on workflow behavior and build on earlier LangGraph concepts without turning the example into a production system.

## Suggested Learning Flow

Concept → architecture → code → run → result → why. Trace at least one representative path through the graph and record the resulting state.
