## How to Use This Repository

Work through stages in order. For each stage, understand the concept, design the smallest useful example, implement it, run it locally, verify its behavior, fix issues, and document what you learned. Keep examples focused on the current stage.

Prefer an available local model or local OpenAI-compatible runtime. Do not add paid cloud APIs unless explicitly approved. Keep examples educational and avoid production infrastructure.

## Stage Verification

Each stage should record the Python, LangChain, and LangGraph versions; the model/runtime; commands actually executed; test results; the end-to-end result; and any blockers. Only report a passing result after real execution. See each stage README for its verification record.
